# DBT + Snowflake Using VS Code

## About This Project

This project is all about learning and revisiting dbt concepts while working with Snowflake using VS Code.

I am using this project to strengthen my understanding of dbt, practice SQL, and explore how different dbt features work through hands-on examples. The idea is to start with the basics and gradually move toward more advanced concepts.

## What I am Learning

- **Models:** Creating SQL models and transforming data using dbt.
- **Macros:** Writing reusable SQL logic.
- **Seeds:** Loading static data from CSV files.
- **Snapshots:** Tracking changes in data over time.
- **Jinja with SQL:** Practicing basic to advanced Jinja syntax, including variables, loops, and conditional statements.
- **Sources & Tests:** Working with source definitions and data quality checks.
- **Materializations:** Understanding views, tables, and incremental models.

## Tools & Technologies

- Snowflake
- dbt
- Visual Studio Code (VS Code)
- SQL & Jinja
- Git & GitHub

## My Goal

The goal is to get more comfortable working with dbt and Snowflake, revisit concepts I already know, and learn new things along the way.

I will keep adding examples and updating the project as I explore more dbt features and improve my skills.
